# Didaktik-Leitplanken

## Lernpfad (Aufbau jedes Tools)
1. **Beobachten:** Das Tool zeigt etwas vor (z. B. Wasser gleicht sich aus, Ausgleichslinie sichtbar). Kind schaut, vergleicht, beschreibt.
2. **Vorhersage:** Kind schätzt oder berechnet, bevor das Tool die Lösung zeigt (z. B. „Wie viel ml sind es pro Becher?").
3. **Selbst bauen/anwenden:** Kind arbeitet selbst (Pipette, eigene Startmengen im Expertenmodus) und prüft das Ergebnis.

Der Aufbau orientiert sich am didaktischen Konzept des Dozenten-Tools „Wasserlabor". Übernommen wird der Aufbau, nicht der Quellcode.

## Führung durch das Tool
- Willkommensfenster beim Start: kurz (höchstens 3 Sätze), Ziel des Tools, ein Button „Los geht's".
- Lernkarten führen Schritt für Schritt durch das Tool (geplant für die iPad-Version, Oktober bis Dezember 2026).
- Immer nur eine Aufgabe sichtbar; Hilfen schrittweise einblendbar statt alles gleichzeitig.

## Differenzierung
- **Anfängermodus:** feste didaktische Startmengen, nur ganze Zahlen, Gesamtmenge durch Kinderzahl teilbar, Hilfen (Ausgleichslinie, exakter Ausgleich) aktiv.
- **Expertenmodus:** Becher starten bei 0 ml, Startmengen selbst einstellbar, Dezimalzahlen erlaubt, Hilfen standardmäßig aus.

## Sprache und Rückmeldung
- Kurze Sätze, Alltagswörter, Fachwort „Ausgleichswert" immer mit Erklärung beim ersten Auftreten.
- Rückmeldung ermutigend und konkret („Fast: Becher 3 ist noch 2 ml zu voll"), nie nur „falsch".
- Fehler als Lernanlass behandeln: erst Vermutung des Kindes, dann Hinweis.

## Einsatzkontext
- Grundschule (4. Klasse): wenig Text, große Bedienelemente, Vorlesen/Piktogramme prüfen.
- Sekundarstufe I (Workshop 6. Klasse, Februar 2027): mehr Eigenständigkeit, Vorhersage und Begründung schriftlich.
- Das Tool begleitet eine Unterrichtsreihe, ersetzt sie nicht. Lehrkraft-Presets bleiben erhalten.
